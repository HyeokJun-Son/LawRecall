# Law Recall v0.4

법규 암기 테스트 앱의 네 번째 프로토타입입니다.

## 이번 버전의 목표

사용자가 작성한 답안을 유지한 채 정답을 함께 비교할 수 있도록 하는 것입니다.

## 추가된 기능

- 문제 화면에서 `정답 보기`를 누르면 오른쪽에 정답 패널이 열립니다.
- 사용자가 작성한 답안은 사라지지 않습니다.
- 내 답안과 정답을 각각 독립적으로 스크롤할 수 있습니다.
- `닫기` 버튼으로 정답 패널만 닫을 수 있습니다.
- 휴대폰에서는 정답 패널이 하단 팝업 형태로 표시됩니다.
- 임시 정답 데이터를 목차와 줄글로 분리하여 저장했습니다.

## 시험범위

- 목차 전체: 해당 논점의 마지막 목차 수준까지
- 모든 내용: 목차 전체 + 줄글

## 아직 포함하지 않은 기능

- 목차 및 줄글 O/X 체크
- 시험 결과 저장
- 실제 Master DB 연결
- 통계 및 복습 추천

## GitHub 반영 방법

1. ZIP 파일의 압축을 풉니다.
2. 저장소의 기존 파일을 새 파일로 교체합니다.
3. 변경사항을 Commit 합니다.
4. GitHub Pages 주소를 새로고침합니다.

## 다음 버전

v0.5에서는 정답 패널 안에서 각 목차와 줄글을 O/X로 직접 채점하는 기능을 추가할 예정입니다.
