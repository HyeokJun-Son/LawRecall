# Law Recall v0.3

법규 암기 테스트 앱의 세 번째 프로토타입입니다.

## 이번 버전에서 변경된 점

- 과목을 여러 개 선택할 수 있습니다.
- 등급을 여러 개 선택할 수 있습니다.
- 시험범위를 두 가지로 정리했습니다.
  - 목차 전체: 해당 논점의 마지막 목차 수준까지
  - 모든 내용: 목차 전체 + 줄글
- 시험 설정을 완료하면 임시 논점 중 하나가 무작위로 출제됩니다.
- 문제 화면에 다음 정보가 표시됩니다.
  - 과목
  - 장
  - 논점 번호
  - 논점명
  - 등급
  - 시험범위
- 답안 입력창을 추가했습니다.
- 작성한 답안은 저장하지 않습니다.
- 정답 보기 버튼은 다음 버전의 정답 비교 화면으로 연결되는 임시 화면을 표시합니다.

## GitHub Pages에 반영하는 방법

1. ZIP 파일의 압축을 풉니다.
2. 기존 저장소의 `index.html`, `style.css`, `app.js`, `README.md`를 새 파일로 교체합니다.
3. 변경사항을 Commit 합니다.
4. GitHub Pages 주소를 새로고침합니다.
