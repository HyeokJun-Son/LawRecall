LawRecall v0.5.0

업데이트 내용
- PDF 라이브러리 추가
- PDF 여러 개 동시 등록 가능
- 한 PDF를 여러 과목에 연결 가능
- 한 과목에 여러 PDF 연결 가능
- 행정법 PDF 2개 연결 지원
- 개별법 PDF 1개를 토지보상법/부동산공시법/감정평가법에 공동 연결 가능
- 파일명, 용량, 등록일 표시
- 앱 표시 이름 변경 및 삭제 지원
- 시험 중 연결된 PDF 사이 전환 가능
- v0.4 이전 과목별 PDF는 가능한 경우 새 라이브러리 구조로 자동 이전

권장 등록 예시
1. PDF 관리에서 행정법①.pdf, 행정법②.pdf, 개별법.pdf를 추가합니다.
2. 행정법에는 행정법①.pdf와 행정법②.pdf를 연결합니다.
3. 토지보상법, 부동산공시법, 감정평가법에는 개별법.pdf를 각각 연결합니다.

저장 안내
- PDF는 GitHub 또는 외부 서버에 업로드되지 않습니다.
- 현재 기기의 현재 브라우저 IndexedDB에만 저장됩니다.
- 브라우저 데이터 삭제, 시크릿 모드, 다른 브라우저 또는 다른 기기에서는 다시 등록해야 합니다.
